# EnLearn 系统核心功能卖点清单

## 一句话定位

EnLearn 是一套面向企业内部管理、制造 MES、审批协同和业务自动化场景的低代码应用平台，支持从页面搭建、数据接入、流程编排到移动端运行的一体化交付。

## 核心卖点

- 低代码页面快速搭建：通过可视化设计器配置页面、表单、表格、详情、统计卡等常见业务组件，减少重复开发。
- 同一套 Schema 多端复用：Web 端设计的业务页面 Schema 可以被移动端运行时消费，降低多端重复建设成本。
- 统一服务调用入口：前端通过统一的 `/api/service` 协议调用后端服务，便于权限、审计、扩展和维护。
- 可视化工作流编排：支持审批流、数据同步流、AI Agent 流等多类流程，通过节点和连线表达业务逻辑。
- 审批自动化能力：支持人工审批、条件分支、超时、等待点、通知和审计等企业流程常见能力。
- 定时与异步任务执行：结合 Trigger.dev 作为内部执行引擎，支持计划任务、批量任务、等待任务和后台编排。
- 移动 MES 运行能力：提供 Hippy + Vue 3 移动运行时，适合制造现场、仓储、销售订单、工单等移动业务场景。
- 移动端高性能表格：支持虚拟滚动、固定表头、固定列、本地排序、行选择和行操作，适合大量业务数据浏览。
- 离线写入队列：移动端可选支持离线表单写入、稳定请求 ID、重试退避和恢复联网后自动回放。
- 原生能力桥接：预留扫码、拍照、相册、文件选择、签名上传、推送 Token 等移动原生能力接口。
- 权限感知导航：移动端和业务页面可根据用户权限动态加载导航和页面入口。
- 页面数据缓存：支持按用户和账套隔离的页面与数据缓存，提升移动端访问体验。
- 可扩展物料体系：支持注册自定义页面块、表单字段和属性表单，方便沉淀企业专属业务组件。
- 运行时事件指令系统：页面组件可以通过事件和指令实现刷新数据、调用服务、路由跳转、消息提示和局部状态更新。
- 发布与版本管理基础：低代码页面支持草稿、发布、归档和版本递增，便于页面生命周期管理。
- 后端边界清晰：工作流编辑器输出框架无关执行计划，实际任务注册、鉴权、密钥和执行由后端适配层掌控。
- 面向企业集成：服务网关、工作流、移动端、文件上传、审批记录和账号套选择等能力便于接入现有业务系统。

## 30 秒宣传话术

很多企业内部系统最大的问题，不是不能做，而是每次业务变化都要重新开发。

EnLearn 把低代码页面、统一服务网关、可视化工作流和移动 MES 运行时整合到一起。页面可以配置，审批可以编排，移动端可以扫码、看表格、提交表单，还支持可选离线写入。

它适合制造、订单、审批、工单和企业内部管理系统，让业务系统从一次性开发，变成可以持续沉淀和复用的平台能力。
